# 心绘 GLM

基于 Vue 的心理数据探索与智能心理支持项目，分为产品官网和面向日常使用的心绘应用。官网保留产品介绍、公开数据和技术说明；应用采用暖白与鼠尾草绿视觉，电脑使用侧栏，手机使用底部导航。

产品模型以本地 GLM 基础模型为底座，围绕心理支持场景训练形成心绘 GLM。官网首页与技术亮点使用同一模型叙述。

## 页面与交互

- 首页：品牌说明、对话与图表预览、考试压力 / 人际关系 / 睡眠困扰 / 工作压力四个话题入口，以及四种陪伴风格。
- 陈列馆：趋势、地区、人群、情绪和关键词五类视图。桌面展示总览，手机按分类切换。地区筛选、地图选择、详情和支持入口共用当前状态。
- 数据库：筛选与记录在前，桌面表格、手机可展开记录，保留字段和数据说明。
- 案例中心：主题与关键词搜索，高级筛选可展开；详情保留来源、局限与核验说明，增加章节目录和类似困扰入口。
- 官网右侧入口：进入心绘应用、下载 / 安装；原“智能支持”链接继续兼容并转入应用聊天页。
- 技术亮点：本地 GLM 基座、心理支持场景训练、心绘 GLM 的模型形成路线，以及输入、安全处理、模型回应与界面呈现流程。
- 应用场景：具体使用情境、现有 Web 能力及后续推广形态。

用户应用以四个常用页面组织，并提供应用内案例阅读：

- `/app` 今天：按时段问候、心情速记、呼吸练习、最近对话和常用操作。
- `/app/chat` 陪伴：文字和语音、多会话、四种陪伴风格、情绪洞察、取消与重试；宽桌面显示右侧历史，手机使用抽屉，输入区适配可见视口。
- `/app/mood` 心情：本地心情日记、最近七天的天气、历史记录及删除确认；未保存草稿在本次打开期间可跨页面继续。
- `/app/me` 我的：昵称、减少动画偏好、记录去向说明、JSON 导出和安装入口，无需注册账号。
- `/app/library` 与 `/app/library/:slug` 阅读：复用公开案例内容和搜索筛选。详情、推荐、返回列表和进入陪伴均留在应用内，保留桌面侧栏与手机底部导航。

官网案例仍使用 `/cases` 与 `/cases/:slug`。应用入口和官网入口共享同一份案例资料，均保留来源、核验状态和局限说明。

内置温柔陪伴、理性梳理、积极教练、沉稳倾听四种风格，沿用已有名称、系统声音和自定义功能。心理支持内容不能替代专业服务；群体统计为展示样例。

## 本地运行

```bash
npm ci
```

按需在本地创建配置文件：

```powershell
Copy-Item .env.example .env
```

```bash
npm run dev
```

前端默认使用 `http://127.0.0.1:5173`，端口占用时 Vite 会选择下一个可用端口，以终端输出为准。API 默认为 `http://127.0.0.1:8787`。本轮验收预览使用 `http://127.0.0.1:5174`。

## 模型接口

保留同源 `/api/chat`、`/api/health` 及原有 JSON 结构。本仓库当前的 Express 与 Worker 仍使用 DeepSeek Anthropic 兼容适配器，它是现有 Web 接入实现，不是心绘 GLM 的训练底座。本次官网说明调整没有切换实际调用链路；接入训练后的本地心绘 GLM 需要推理服务的地址、模型标识及接口协议。

以下配置对应仓库中现有适配器：

```dotenv
ANTHROPIC_BASE_URL=https://api.deepseek.com/anthropic
ANTHROPIC_AUTH_TOKEN=你的_API_Key
ANTHROPIC_MODEL=deepseek-v4-pro
PORT=8787
```

模型名称由服务端配置决定，应按实际账号可用模型调整。真实密钥仅保存在本地 `.env` 或托管环境中，不能放入前端代码。

未配置密钥时返回基础支持；上游服务失败时，响应增加 `X-Chat-Fallback: upstream` 标记，原有 JSON 回复结构保持兼容。前端显示服务失败说明，并提供重试。

## 对话行为

- 桌面 Enter 发送，Shift + Enter 换行；中文输入法选字期间不发送。手机 Enter 换行，使用发送按钮提交。
- 输入最多 4000 字符，输入区自动增高至四行。
- 草稿和发送状态按会话维护。等待期间可以切换或新建会话，回复仍写入请求发起时的会话与陪伴风格；删除原会话后丢弃迟到回复。
- 请求默认 25 秒超时，支持停止回应和失败重试。重试复用原用户消息，并替换该次基础支持回复。
- 浏览器保留完整历史；接口只发送最近最多 30 条消息，完整 JSON 请求体按 UTF-8 控制在 24 KiB 以内。
- 本地保存失败时提示未保存，对话可继续，发送状态正常复位。
- 兼容原有 `xinhui-consultation`、版本 1 的本地记录，新增字段为可选字段。

快捷链接示例：

```text
/consultation?topic=exam
/consultation?topic=relationships
/consultation?topic=sleep
/consultation?topic=work
/consultation?case=test-anxiety-adolescent
/consultation?case=case-001&region=广东&population=大学生&emotion=焦虑
/app/chat?topic=exam
/app/chat?case=test-anxiety-adolescent
```

有效话题或案例链接会新建会话并预填可编辑文字，不自动发送。消费后移除 `topic` / `case` 参数，保留地区、人群和情绪参数，刷新不会重复创建会话。

旧 `/consultation` 链接会保留查询参数并转入 `/app/chat`。

## 语音与记录

语音识别和朗读依赖浏览器 Web Speech API、设备权限和系统音色。项目服务端不接收原始录音；浏览器的识别服务可能使用其自身的网络服务。识别不可用时可直接返回文字对话。

记录保存在当前浏览器的 `localStorage`。在线对话会将裁剪后的消息、背景和陪伴风格发送到模型服务；自定义风格不会覆盖安全规则。危机表达优先进入客户端与服务端安全响应。

心情日记、昵称和界面偏好保存在独立的本地记录中，不发送给模型。保存前读取最新记录，并通过浏览器存储事件同步其他页面的变更。清除浏览器数据或更换设备后，不会自动恢复；可以在“我的”中导出记录。

## 网页安装

官网与应用内提供手机 / 电脑安装说明。浏览器支持时可以直接触发安装，其他情况可按指引添加到桌面或手机主屏幕。Windows、macOS、Android 和 iOS 原生安装包尚未发布。

应用已包含 PWA manifest、图标与 service worker，启动入口和作用域为 `/app`；仅在生产构建的安全环境中注册。离线重新打开时提供连接提示，不缓存个人记录、聊天请求或模型回复，也不提供完整离线应用。开发预览主要用于界面和交互验收，系统级安装仍需在实际设备验证。
