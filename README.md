# 心绘 GLM

心绘 GLM 是一个“心理数据洞察 + 智能心理支持”平台。产品连接群体趋势分析、安全对话、持续会话记忆、医生人格定制与浏览器语音陪伴，形成“识别 → 分析 → 支持”的完整链路。

> 本项目提供非诊断性心理支持，不能替代专业心理咨询、医疗服务或紧急救助。统计内容为匿名化聚合数据，用于展示群体趋势，不代表真实流行病学结论。

## 核心能力

- 心理数据陈列馆：趋势折线图、覆盖 34 个省级区域的中国地图、人群雷达图、情绪构成和关键词云。
- 智能心理支持：通过服务端安全代理调用 DeepSeek，返回结构化中文支持回复。
- 多会话记忆：支持新建、切换、重命名、删除和刷新恢复，对话保存在当前浏览器。
- 医生人格：内置温柔陪伴、理性梳理、积极教练、沉稳倾听四种人格，也可自定义名称、沟通方式和声音。
- 语音通话：使用浏览器语音识别和系统中文语音合成，不上传原始录音。
- 双层安全策略：客户端与服务端优先识别危机表达，安全分流不受医生人格影响。

## 页面

- 首页：产品价值、核心入口、指标预览和“识别 → 分析 → 干预”链路。
- 陈列馆：五类联动图表与四维筛选上下文。
- 数据库：数据来源、治理流程、四维标签体系和聚合记录。
- 智能支持：多会话、在线模型、医生人格、语音通话、情绪洞察和危机提示。
- 技术亮点：DeepSeek、安全策略、会话记忆、人格化交互和数据可视化。
- 应用场景：学校、医院、社区和心理咨询机构。

## DeepSeek 配置

服务端使用 DeepSeek 的 Anthropic 兼容接口，真实密钥只能写入本地 `.env`：

```bash
ANTHROPIC_BASE_URL=https://api.deepseek.com/anthropic
ANTHROPIC_AUTH_TOKEN=你的_API_Key
ANTHROPIC_MODEL=deepseek-v4-pro
PORT=8787
```

模型应使用官方 ID `deepseek-v4-pro`。DeepSeek 的 Anthropic 兼容说明见[官方文档](https://api-docs.deepseek.com/guides/anthropic_api)。

密钥不会发送到浏览器，也不会出现在健康检查响应中。前端只请求同源 `/api/chat`，由 Express 代理调用模型；上游不可用时自动提供基础心理支持和安全提示。

## 语音说明

- 推荐使用最新版 Chrome 或 Edge。
- 首次点击麦克风时，浏览器会请求麦克风权限。
- 中文声音来自操作系统和浏览器；可用声音因设备而异。
- 原始录音不会写入会话，也不会上传到项目服务端。
- 浏览器不支持语音识别时，文字对话和回复朗读仍可独立使用。

## 会话与隐私

- 会话保存在浏览器 `localStorage`，不会构成医疗记录。
- 用户可以在会话侧栏中随时改名或删除对话。
- 自定义医生人格仅影响表达语气与声音，不能覆盖非诊断和危机分流规则。

## 安全边界

- 不输出医学诊断或确定性疾病判断。
- 普通回复按共情、情绪识别、具体行动和专业帮助提示组织。
- 自伤、自杀、伤害他人等表达会优先进入危机响应。
- 危机响应建议立即联系当地急救、附近医院急诊、专业危机资源或身边可信赖的人。
- `.env` 已被 `.gitignore` 忽略；不要把真实密钥写入文档、源码或前端环境变量。

## 数据与地图

聚合统计数据位于 `src/data/mock/`。中国地图 GeoJSON 已随项目本地化，来源为阿里云 DataV 地理数据服务，页面运行时不依赖第三方地图请求。
