# 用户端视觉调整

目标：按两张新参考图调整桌面与手机软件界面，延续官网温暖色调，加大文字和动效幅度。官网作为品牌依据，现有 API、记录、语音与应用内阅读流程继续工作。

- 视觉：奶油白底、杏桃与蜜黄色光晕、青绿色主要操作；少量雾蓝点缀。背景光晕覆盖整个应用，卡片和输入框使用半透明表面。
- 布局：首页使用居中的陪伴光球、问候、可输入的对话入口，下方保留常用操作、心情记录和最近对话；聊天页使用同一光球与输入框语言。
- 字体：正文 / 输入 16px，操作 15–16px，辅助文字至少 14px；装饰英文允许 12px。覆盖首页、聊天、心情、我的、阅读与弹窗。
- 动效：光球浮动约 27px、光晕移动约 60–90px，页面入场约 28px、卡片悬停约 7px；支持系统减少动画和安静模式。
- 验证：构建与完整测试；320 / 390 / 768 / 1440 所有应用页、弹窗、短聊天视口；字体检查、动效采样、安静模式、首页对话入口及阅读与心情交互；截图目视对照参考图。
