# 心绘官网与用户应用分层

官网保留产品介绍和公开数据，应用提供日常陪伴。参考智行校园的独立官网 / 应用入口与用户图片的轻量卡片、留白和淡彩。沿用现有 Vue、对话状态和服务接口，不复制聊天实现。

## 协作契约

- 根任务负责官网导航、应用壳、/app 路由、今天 / 心情 / 我的页和本地生活记录；应用桌面侧栏 224px、顶栏 72px，手机顶栏 60px、底栏 70px + 安全区。
- 聊天任务仅调整 ConsultationPage、ChatWindow：应用模式不重复官网导航和会话侧栏；保留输入、草稿、语音、多会话及安全响应。短可见视口中输入保持可见。
- 安装任务负责独立安装弹窗、浏览器安装事件、manifest / 图标 / service worker、main 注册。真实支持网页安装，未发布原生包明确说明。API 与个人记录不得进入缓存。
- 调研任务只读验证参考站布局、浏览器工具与关键验收项。

## 顺序与验证

1. 明确路由与壳尺寸后并行实现；旧 /consultation 链接保留参数导向 /app/chat。
2. 集成各部分，验证类型与现有测试；新增记录持久化与路由兼容的必要测试。
3. 本地浏览器检查 320 / 390 / 768 / 1440 四宽度、短视口、官网入口、聊天、记录、呼吸、个人设置和安装弹窗。
4. 保存桌面和手机预览截图、完成实现说明；原生安装包与真实设备权限的边界如实说明。
