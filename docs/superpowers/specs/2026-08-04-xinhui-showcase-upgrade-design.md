# 心绘 GLM 评委展示版升级设计

## 目标

修复空白词云与地图缺失值，将咨询页升级为可持续使用的多会话体验，并清理仅适合开发阶段、不适合评委观看的内容。

## 可视化

- 词云使用 ECharts 散点文字布局，所有关键词必须获得可见字号与稳定坐标。
- 地图覆盖 GeoJSON 中全部省级行政区，所有地图项必须是有限数值；提示框不得显示 `NaN`。
- 数据说明保留必要的科研诚信表述，但不出现“演示模式”“MVP”“mock”等内部词汇。

## 会话与医生人格

- 会话保存到浏览器 `localStorage`，刷新页面后恢复。
- 支持新建、切换、重命名和删除会话；首条用户消息自动生成标题。
- 内置四种医生人格：温柔陪伴、理性梳理、积极教练、沉稳倾听。
- 支持自定义医生名称、沟通风格和中文声音。
- 当前人格随聊天请求发送到服务端，作为模型系统提示的一部分；人格不得覆盖非诊断、危机分流和安全规则。

## 语音通话

- 使用浏览器原生 SpeechRecognition/Web Speech API 获取语音输入。
- 使用 SpeechSynthesis 播放模型回复，不上传原始录音。
- 各人格根据声音偏好选择不同的中文系统音色，用户可覆盖选择。
- 不支持语音识别时仍可进入通话面板并使用键盘输入，界面明确显示兼容性状态。

## 展示清理

- 首页删除框架版本、MVP 和模拟指标等内部措辞。
- 数据页删除接口地址和开发流水线展示，保留数据治理价值。
- 咨询页不展示 mock、本地演示等技术状态；在线时显示“智能服务已连接”。
- 技术页只展示当前真实实现，不声称已经完成未落地的训练或微调。

## 验证

- 单元测试覆盖完整地图、可见词云、会话持久化、标题编辑、人格请求与语音选择。
- 在桌面和手机视口验证图表、会话切换、人格定制、语音面板和无横向溢出。
- 调用健康接口与真实聊天接口确认 DeepSeek 在线链路。
